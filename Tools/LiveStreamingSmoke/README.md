# iOSライブ配信

アプリの「ライブ配信」からYouTube、Twitch、ツイキャスを1つ以上選択し、
各サービスの外部ツール配信画面で取得したサーバーURLとストリームキーを入力します。
「配信開始」を押すとReplayKitでアプリ画面とマイクを取得し、選択した先へ送信します。
実際の公開開始操作や配信資格は各サービス側の設定に従います。

URLとキーは端末固有のKeychainに保存します。チャットやGitへの記入は不要です。
設定画面は配信開始前に閉じ、配信中は開けません。
録画との同時使用はできません。バックグラウンドに移ると配信を終了します。

送信はH.264/AAC、最大辺1280px、最大30fps、映像2Mbps・音声96kbpsを配信先ごとに使用します。
接続状態を個別に表示し、通信断の先だけ5秒後に再接続します。
キー拒否時は自動再試行せず、終了して設定を修正します。
HaishinKit 1.9.9 / Logboard 2.5.0を固定して使用します。

## 検証

Mac上で `brew install mediamtx ffmpeg` 後、リポジトリのルートから
`python3 Tools/LiveStreamingSmoke/run.py` を実行します。
本番のSwift送信クラスを抽出し、ローカルRTMPサーバーへ3本同時に映像と音声を送ります。
受信ファイルのH.264/AAC、解像度、全フレームのデコード、接続失敗の独立性と停止状態を確認します。
結果・ソースハッシュ・受信映像・ログは `Output/live-streaming-smoke/` に保存します。
GitHubのIPAビルドもこの検証に成功することを必要条件とします。

この検証は公開配信を行いません。iPhoneのReplayKitとカメラの同時動作、マイク、
画面回転、モザイクを含む映像、各サービスの認証・公開状態は実機で確認が必要です。
