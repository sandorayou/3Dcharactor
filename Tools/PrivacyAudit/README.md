# Windows/iOS privacy parity audit

Run on macOS: `clang++ -std=c++14 -O2 Tools/PrivacyAudit/audit.cpp -o /tmp/privacy-audit && /tmp/privacy-audit Tools/PrivacyAudit/cases`.

The executable calls the exact C++ header used by the iOS app. Six deterministic synthetic BGRA fixtures cover portrait/landscape, two explicit camera presets, eye holes edge regions, initial calibration outside the strict seed and a no-person wall. Gold masks and pixels were generated by the current Windows Python runtime with the same inputs and parameters. Masks must be byte-identical after eight calibration frames; area-average mosaic may differ by at most one colour level due to OpenCV rounding. Fixtures contain no user photographs.

Core Image colour and coordinate round trips are separately checked by `audit_core_image.mm`. Neither check establishes real iPhone camera performance or white balance. Device testing remains necessary.
